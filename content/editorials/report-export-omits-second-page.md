Start with the export job. The dashboard shows the correct second page and its extra IDs. The completed file contains the first page only. The contrast is useful triage evidence, but the matching cut at 50 does not prove which query or job step caused it.

Record both pages for the selected fixture, request the export without changing the filter, and download it after completion. Parse the file and compare identifiers, not just the total number of lines. Attach the redacted output and its job ID, and capture the full filter defaults. The report already has the expected and actual counts and the browser version.

The split-by-date procedure gives analysts a supported route, making the impact S3. The finance handoff still makes it P1. The decoy treats the one-click export failure as the only way to produce the report and assigns the defect to a list that already shows the missing records.

See [ISTQB CTFL, defect management](https://istqb.org/wp-content/uploads/2024/11/ISTQB_CTFL_Syllabus_v4.0.1.pdf). An interviewer listens for exact evidence of which rows went missing.
